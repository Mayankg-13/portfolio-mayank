## 🛠️ Tech Stack & Technologies

- **Frontend**: React.js, Tailwind CSS, Lucide Icons, Framer Motion, Canvas Confetti
- **Build Tool**: Vite
- **Deployment**: Vercel

---

## 📄 Key Features

- **Warm & Classy Editorial UI**: Responsive, modern layout with custom typography and subtle micro-animations.
- **Interactive Project Simulators**: Real-time interactive model comparison, role-based auth workflow simulation, and RAG multilingual pipeline visualizers.
- **Quick Navigation Command Palette (`⌘K` / `Ctrl+K`)**: Keyboard search across sections, projects, and links.
- **Resume Modal & Direct PDF Access**: View key resume highlights and access Google Drive PDF directly.
- **Direct Message Form**: Interactive contact form with feedback and confetti trigger.

## 💻 Local Development Setup

```bash
# Clone the repository

# Navigate to project directory
cd portfolio-mayank

# Install dependencies
npm install

# Run dev server
npm run dev
```
